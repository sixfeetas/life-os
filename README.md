# Life OS

记录 · 计划 · 自省 —— 单页应用，纯前端，无后端。

## 使用

打开 `https://<你的用户名>.github.io/<仓库名>/` 即可。

数据存在**你自己的浏览器**里，不会上传到任何服务器。

## 三个 tab

- **记录**：计时、情绪、补记、时间轴
- **计划**：任务卡（预估 vs 实际）、超时追问、顺延提醒
- **自省**：观点卡（3 次证据才内化）、落地率、结果锚点、AI 分析对话

## 部署

根目录已包含 `.nojekyll`，直接开启 GitHub Pages（分支 main / 根目录）即可。

## 注意

纯前端应用，仓库里**没有任何密钥**。AI 的 API Key 由使用者自己在浏览器里填，只存在本地。
