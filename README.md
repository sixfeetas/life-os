# Life OS

记录 · 计划 · 自省 —— 纯前端单页应用，不需要服务器。

线上地址：<https://sixfeetas.github.io/life-os/>

## 数据存在哪里

- 数据保存在打开网页的这台设备和这个浏览器里，刷新、关闭页面都不会丢。
- 换一台设备、换一个浏览器，或使用无痕模式时，会看到各自独立的数据。
- 清理浏览器网站数据、卸载浏览器后，本地记录也会被删除。
- 程序会保留一份同浏览器的恢复快照，并在每次保存后读回校验。
- 建议每周点一次右上角“导出全部备份”，把 JSON 文件保存到网盘或电脑。
- 新设备上点右上角“从备份恢复”，选择 JSON 文件即可导入。
- 导出的备份不包含 AI API Key。

## 打开和安装

直接打开线上地址即可。手机浏览器里选择“添加到主屏幕”，之后就能像 App 一样打开。

不要双击 `index.html` 使用。本机文件地址通常会被浏览器禁用持久存储，数据可能关掉页面后就消失。

## 三个 tab

- **记录**：计时、情绪、补记、时间轴
- **计划**：任务卡（预估 vs 实际）、超时追问、顺延提醒
- **自省**：观点卡（3 次证据才内化）、落地率、结果锚点、AI 分析对话

## GitHub Pages

仓库里已包含自动部署工作流。推送到 `main` 后，GitHub Actions 会自动发布网页并尝试开启 Pages，不需要手动配置构建命令。

发布新版时，双击 `推送.cmd`。第一次推送需要在弹出的 GitHub 登录窗口完成登录。

## 找不到旧记录时

1. 先确认打开的是线上网址，而不是本地 `index.html`。
2. 确认使用同一个浏览器、同一个浏览器用户配置。
3. 不要先清理浏览器站点数据。
4. 如果有 JSON 备份，点右上角“从备份恢复”导入。

纯前端版本不会跨设备自动同步。仓库里没有任何密钥，AI API Key 只保存在当前浏览器。
